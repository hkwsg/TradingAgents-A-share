# 资料卡模板规范

## 设计原则
- emoji 分区 + 分隔线 + 短句，不做表格堆砌
- 一句话结论最顶上，方便快速判断
- 好坏两面并列展开，让读者自己感受矛盾
- 执行方案区分角色给指令，不是泛泛的建议关注
- 入场信号具体到数字和K线形态，不写待观察这种废话
- 止损线必须有明确价格和跌破理由
- 结尾用组合经理原话压轴，给整张卡一个人味

## 固定模块
1. 头部指标条（日期/现价/跌幅/周期）
2. 最终评级（SELL/HOLD/BUY + 简短描述）
3. 一句话结论
4. 好的一面（✅ 列表，3-6条，数据驱动）
5. 坏的一面（🔻 列表，3-6条，逻辑驱动）
6. 执行方案（按持仓状态分角色，🟢/🔴 标注）
7. 入场信号/加仓计划（含价格锚点和K线形态）
8. 止损线（有价格，有理由）
9. 组合经理原话（一句有温度的话收尾，必加）

## 语言风格
- 中文简洁口语化，像跟朋友说人话
- 不写建议投资者密切关注需持续跟踪这类官腔
- 不复制完整报告，只提炼最有杀伤力的那几个数字和逻辑
- 执行方案用祈使句：不要XXX、立即XXX、禁止XXX

## 评级颜色映射
- SELL/Underweight → 🔴 标签
- HOLD/Neutral → 🟡 标签
- BUY/Overweight → 🟢 标签

## 图像版自动化

文字版资料卡生成后，使用脚本自动渲染为图像版：

```bash
py scripts/render_card_image.py reports/<代码>_<日期>/<股票名>_资料卡.md
```

默认输出：
- `reports/<代码>_<日期>/<股票名>_资料卡_图像版.html`
- `reports/<代码>_<日期>/<股票名>_资料卡_图像版.png`

如需指定文件名：

```bash
py scripts/render_card_image.py reports/600276_2026-06-05/恒瑞医药_资料卡.md --output reports/600276_2026-06-05/恒瑞医药_资料卡_专业蓝_单列阅读.png
```

脚本流程：
1. 读取 markdown 资料卡
2. 生成专业蓝单列 HTML
3. 调用本机 Chrome/Edge headless 截图
4. 自动裁剪底部空白

当前设计基线：
- 主色：深蓝 / 蓝灰，偏券商研报风格
- 正文：从「一句话结论」后采用全宽单列阅读
- emoji：保留，但用于信息锚点，不作为大面积装饰
- 「什么时候能买」展示图标使用 🎯

## 组合经理原话摘录技巧
- 从 Portfolio Manager Decision 或 Research Manager 的最终裁决中找
- 选最有张力、最像人说的话，不要选数据陈列句
- 通常出现在报告的结尾段落或裁决总结部分
- 好例子：不是不买，是等一个更好的价格。不是恐惧，是纪律。
- 好例子：在熊市中不亏钱就是赢家。你现在的耐心，就是对未来利润最好的投资。
- 坏例子：本决策建立在对多空双方辩论的全面评估之上。（太官腔，不能用）
